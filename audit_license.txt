1.2. BASE DE TREINAMENTO (DATASET)
--------------------------------------------------------------------------------

Dataset principal: WIDER FACE
    - Site oficial: http://shuoyang1213.me/WIDERFACE/
    - Paper: Yang, S., Luo, P., Loy, C. C., & Tang, X. (2016).
      "WIDER FACE: A Face Detection Benchmark". CVPR 2016.
      arXiv: https://arxiv.org/abs/1511.06523

Composição do WIDER FACE:
    - 32.203 imagens
    - 393.703 rostos anotados
    - 61 classes de eventos
    - Split padrão: 40% treino / 10% validação / 50% teste

Licença do WIDER FACE:
    - O dataset é disponibilizado para fins de pesquisa acadêmica.
    - O modelo YuNet pré-treinado é distribuído sob MIT; o uso do modelo
      NÃO requer redistribuição do dataset original.
    - Para retreinar com WIDER FACE, consulte os termos no site oficial.

Nota: O script de carregamento do WIDER FACE no HuggingFace Datasets
declara licença como "Unknown" no cabeçalho do arquivo, refletindo a
ambiguidade da licença do dataset original [citation:9]. Isso NÃO afeta
o uso do modelo pré-treinado sob MIT.

1.3. PERFORMANCE E MÉTRICAS
--------------------------------------------------------------------------------

Métricas oficiais (WIDER Face validation, paper YuNet):
    - Easy AP:   0.834
    - Medium AP: 0.824
    - Hard AP:   0.708

Métricas reavaliadas no OpenCV Zoo:
    - Easy AP:   0.8844
    - Medium AP: 0.8656
    - Hard AP:   0.7503

Nota: A diferença reflete variações no pipeline de avaliação (pré-
processamento, NMS, thresholds). Ambas as fontes são válidas.

--------------------------------------------------------------------------------
1.4. ESPECIFICAÇÕES TÉCNICAS
--------------------------------------------------------------------------------

Arquitetura:
    - Detector facial anchor-free baseado em CNN leve.
    - Projetado para dispositivos edge/mobile.

Tamanho do modelo:
    - ~0.3 MB (FP16)

Velocidade de inferência:
    - ~4 ms por frame em GPU móvel (Pixel 8a, Tensor G3) via LiteRT,
      entrada 640×640.
    - 1.6 ms/frame a 320×320 em CPU desktop (Intel i7-12700K) .

Faixa de detecção otimizada:
    - Rostos entre 10×10 e 300×300 pixels.

Saída do modelo:
    - Bounding box (x, y, w, h)
    - Score de confiança (0.0 a 1.0)
    - 5 landmarks: olho direito, olho esquerdo, ponta do nariz,
      canto direito da boca, canto esquerdo da boca

Formato de exportação:
    - ONNX (utilizado neste projeto via cv2.FaceDetectorYN)
    - Outros formatos disponíveis via libfacedetection.train

Compatibilidade:
    - cv2.FaceDetectorYN.create(...)
    - Requer OpenCV >= 4.5.4.
